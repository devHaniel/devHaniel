# 📌 Proyectos Destacados

### 🧾 HanPOS

Sistema de **Punto de Venta (POS)** orientado a pequeños comercios, diseñado para simplificar la gestión de ventas, inventario y operaciones de caja.

**Tecnologías:**

`C#` `ASP.NET Core` `Entity Framework Core` `PostgreSQL` `Vue.js` `TypeScript` `Docker`

**Características principales:**

* Gestión de productos y categorías
* Control de inventario
* Gestión de clientes y proveedores
* Ventas y compras
* Gestión y apertura/cierre de caja
* Movimientos de efectivo
* Autenticación y autorización
* Roles de usuario
* API REST
* Aplicación frontend integrada con la API

---

### 📅 Sistema de Reservas

Sistema de **gestión de reservas** desarrollado para administrar usuarios, reservas y disponibilidad, incorporando comunicación en tiempo real mediante **SignalR**.

**Tecnologías:**

`C#` `ASP.NET Core` `Entity Framework Core` `PostgreSQL` `Vue.js` `TypeScript` `SignalR` `Docker`

**Características principales:**

* Gestión de reservas
* Control de disponibilidad
* Autenticación y autorización mediante JWT
* Gestión de usuarios y roles
* Actualizaciones en tiempo real con **SignalR**
* API REST
* Persistencia con Entity Framework Core
* PostgreSQL como base de datos
* Frontend desarrollado con Vue.js y TypeScript
* Aplicación completamente containerizada con Docker
